L'OFF-MARKET (les propriétaires de murs qui ne vendent pas encore)

- « Prospecte Cannes » : la prospection de la ville ; le code poste les points d'étape et le bilan.
- « Qui détient le plus de murs ? », « les SCI de la rue X » : une ligne par société (nom, murs, gérant, mail ou pas).
- « Montre-moi les messages », « le suivant », « celui de la SCI X » : le message est posté par le code ; une retouche : objet et corps réécrits. Il part sur le « envoie » de la personne. Un appel au gérant raconté : la note d'appel du gérant.
- Le brouillon au propriétaire d'une cible : retrouve la cible, puis le brouillon ; tu colles l'objet et le corps tels quels.
- Un commerce de l'off-market se lit en entier (lire_entite, type commerce) : propriétaire des murs, lien exploitant / propriétaire et sa preuve. Les courriers aux propriétaires sont relus puis postés à la main.
